# Preflight qualification

This map connects [PFL-001 through PFL-008](../specs/required-specification.md#19-installation-preflight-milestone-m8) and [AJ-24](../specs/testing-and-acceptance.md#aj-24-non-mutating-installation-preflight) to production paths and checks. It is implementation guidance, not another delivery-status record; [EPIC-014](../roadmap/README.md#epic-014-non-mutating-installation-preflight) alone owns lifecycle. The public command example is [Preflight](../specs/examples/cli-workflow.md#preflight). Normative report behavior remains [section 36](../specs/interfaces-and-operations.md#36-installation-preflight-milestone-m8).

The published v0.1.2 release does not provide this command. A local candidate can still report version 0.1.2. The intended release is unreleased v0.1.3. This map does not publish, install, or accept the Task.

## AJ-24 clauses

| Clause | What the compiled candidate covers | What stays with an earlier owner |
| --- | --- | --- |
| 1 | Absent and empty homes stay uninitialized at fresh/0. A real pre-initialization failure that leaves only `sorage.log` is fresh/0 with a home.state warning and unchanged residue. Permitted logs with empty state and run directories, and nothing else, are the same fresh/0 warning; those empty directories are setup recorded before the baseline. A non-directory, broken link, unreadable home, unknown residue, and partial inventory are not fresh. | Pure fresh fixtures remain TASK-097. |
| 2 | A current installation with no installation singleton, a populated installation, and both a directory binding and a real Git Project whose owned directory was initialized before the baseline, including `.git` in the unchanged inventory and no Project actor, are compatible/0. | None of these three shapes is only an in-process mock. |
| 3 | Populated pre-Memo schema, data, and receipts remain, at upgrade_required/78, with migration wording separate from old-binary backup verification and a separate restore drill. | The command does not perform the external drill. |
| 4 | Missing configuration, database, and marker; invalid history and schema; corrupt bytes; foreign-key failure; and identity or binding mismatch are recovery_required/78. Readable newer configuration, database, and Vault are unsupported/78. | A maximum migration number alone, or a Memo table alone, remains an adapter non-positive classification. The compiled matrix does not repeat those two homes. |
| 5 | Committed WAL participation changes the report from the main file alone. Missing and stale SHM stay on the source. Stable home and configured external Vault aliases are allowed. Linked managed files, escaping links, and a broken root fail closed. Permission denial does not claim an unreadable hash. Live, dead-PID, and malformed file fences, the database move fence, and a migration_lock row that is not a live owner keep stale evidence, with a source.snapshot warning when the evidence is stale. A held writer that does not mutate stays compatible/0. A separate owned actor commits during the native inspection; its progress is observed across that invocation. Cleanup awaits the child exit or close, uses SIGKILL only after a bounded SIGTERM, and only then runs a separate no-write inspection. Active writes stay attributed to the actor. | Changing roots during capture and injected copy, read, parse, and private SQLite failures remain the 42 adapter tests. A writer alone is not reported unverifiable when the committed snapshot is coherent. The mutating actor's actual status is compatible/0 or unverifiable/75 only when that is the report and exit. |
| 6 | Every quiescent compiled success and failure compares home and external Vault hashes, modes, mtimes, dev/ino, names, and absent entries. The compiled child uses an owned TMPDIR outside both roots; the parent TMPDIR is unchanged and the owned scratch is removed. | Injected parse, read, copy, and private SQLite cleanup remains the same 42 adapter tests. ## This host and unperformed checks

The compiled preflight end-to-end file was executed on the current darwin development host. That execution is not a qualification of unchanged access timestamps, operating-system crash, power loss, or an external old-binary backup and restore drill. No such drill was run. Crash and power-loss behavior remain unperformed. Inventory comparisons use hashes, modes, modification times, device and inode identities, names, and absent entries.
