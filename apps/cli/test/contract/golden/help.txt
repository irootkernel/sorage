Usage: sorage [options] [command]

Local document-handoff broker for AI coding sessions.

Options:
  --as <project-slug>             resolve the acting Project by slug instead of
                                  the working directory
  --as-user                       assert the local User as the actor for a
                                  User-admin operation; User-admin rows express
                                  workflow intent, and any process able to run
                                  the CLI as this operating-system user can
                                  assert User context
  --confirm                       confirm a state-conditional operation
  --expected-row-version <n>      compare-and-set against this Row Version
  --limit <n>                     page size for list commands
  --cursor <cursor>               resume a listing from an opaque cursor
  --json                          emit the versioned JSON envelope on standard
                                  output
  -h, --help                      display help for the command

Commands:
  version                         print the product version
  init [options]                  create the Sorage installation: home tree,
                                  configuration, database, and Vault
  uninstall                       remove the Sorage installation while keeping
                                  the Vault
  config                          inspect and change the installation
                                  configuration
  doctor                          run the milestone-scoped installation checks
                                  and report the catalog
  project                         register and inspect Projects and their
                                  bindings
  send [options]                  hand one current document to one or more
                                  recipient Projects, one Handoff each
  inbox [options]                 list the Handoffs sent to the resolved
                                  recipient Project
  outbox [options]                list the Handoffs the resolved sender sent
  get <handoff-id>                read one Handoff's metadata; records nothing
  fetch <handoff-id>              read the current Artifact's metadata and local
                                  path; the recipient's first fetch is recorded
  events <handoff-id>             read the bounded recent metadata timeline;
                                  records nothing
  review                          read, create, withdraw, and remove Review
                                  Notes
  revise [options] <handoff-id>   replace the current Artifact or resolve the
                                  Review Note without changing content
  accept [options] <handoff-id>   accept the exact Revision as the recipient,
                                  closing the exchange
  decline [options] <handoff-id>  decline the Handoff as the recipient with a
                                  recorded reason
  withdraw <handoff-id>           withdraw the Handoff as the sender before the
                                  recipient has engaged
  pin <handoff-id>                pin the Handoff against deletion; a User-admin
                                  operation
  unpin <handoff-id>              release a pinned Handoff; a User-admin
                                  operation
  archive <handoff-id>            archive a terminal Handoff out of the default
                                  listings; a User-admin operation
  unarchive <handoff-id>          return an archived Handoff to the default
                                  listings; a User-admin operation
  delete                          request and decide Handoff deletion
  vault                           inspect, verify, and relocate the Artifact
                                  Vault
  backup                          verify, run, and restore Vault backups
  completion <shell>              print the shell completion script for zsh or
                                  bash; source it from the shell's profile
  daemon                          run and control the local daemon
  web                             start the daemon when needed and open the Web
                                  control plane with a one-time session secret
  token                           manage the Installation API token
  help [command]                  display help for command
