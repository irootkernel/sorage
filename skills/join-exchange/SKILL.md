# Join an Exchange

Read [references/exchange-loop.md](references/exchange-loop.md) from this skill directory before calling Sorage. If the reference is missing or unreadable, stop the dependent operation and report the incomplete copy.

Use the exact existing Exchange ID and the intended active registered Project and Installation. Follow the reference's common join procedure for first entry, reconnect after owner loss, or user-authorized resumption. Report the returned Project, Exchange state and pending work relevant to the request. Use the live claim only when the owner acquired one. A Paused result presents the outstanding decision and a Completed result presents the retained outcome. Resume only with direct user authority and the exact observations for that pause.
